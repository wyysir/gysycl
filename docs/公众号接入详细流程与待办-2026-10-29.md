## 三、备案通过后的操作顺序

### 1. 确认备案与公网访问

用户在阿里云控制台确认审核通过，核对域名和接入信息。无需重新购买域名或重复提交备案。

我再检查www.dhcy.top的DNS及校验文件公网访问，必须返回200和原始文件内容；服务器内部200不能代替公网检查。当前不申请域名证书或切换系统入口。

### 2. 配置域名HTTPS和网页授权域名

1. 留存原配置、镜像、数据库和图片备份及回退依据，继续使用现有应用、数据库和图片持久卷。
2. 配置www.dhcy.top的HTTPS证书和续期，核对健康、登录、已有记录及图片可访问。
3. 在旧版公众号后台“设置与开发 → 账号设置 → 功能设置 → 网页授权域名”保存www.dhcy.top。以当前实际界面为准，填写主机名，不带https://或回调路径。
4. 网页授权域名与服务器回调URL的域名一致。此次基础网页授权和现有H5上传不需要额外申请模板消息能力；没有公众号消息/事件接收端点，不把授权回调填写成消息推送地址。

### 3. 配置微信登录并发布

| 配置项 | 填写原则 |
| --- | --- |
| APP_URL | https://www.dhcy.top，待域名就绪后切换，不带结尾斜杠 |
| WECHAT_APP_ID | 德亨餐饮服务号的AppID |
| WECHAT_APP_SECRET | 同一服务号的AppSecret，仅在服务器私密配置保存，不发送到聊天、日志或Git |

本地代码不再读取WECHAT_TEMPLATE_REVIEW_PENDING或WECHAT_TEMPLATE_REVIEW_RESULT。旧环境即便残留两项也不会被新代码使用，不为取消通知更换AppSecret或撤销客如云授权。

先核对客如云的网页授权协作方式，使用账号实际可用的凭据与权限；不擅自启用、冻结或重置密钥。发布时让Web/Worker使用同一已验证源码和镜像，普通员工号密码入口继续可用。现有configure-trial脚本不能假定会询问微信参数。

取消通知已上线，无须等待备案再部署同一改动。后续域名和微信凭据配置按独立发布节点记录镜像、源包、验证、备份与回退；不要把已有源码能力当作实号验收通过。

### 4. 在客如云新增公众号菜单

用户通过客如云后台编辑现有菜单，增加“采购单据”，类型为跳转网页，链接使用核验后的https://www.dhcy.top/api/auth/wechat/start。

保留原菜单，在真实手机微信中检查发布结果；不能调用创建菜单API覆盖整套客如云菜单，也不能用后台预览代替手机验收。

### 5. 首次绑定与再次进入

1. 用真实微信从菜单进入，未绑定时显示“绑定员工身份”。
2. 使用已有员工号密码，不另建虚构员工或管理员。确认进入工作台，身份、项目权限、已有单据及图片正确。
3. 退出后再次从菜单进入，验证启用账号自动登录。
4. 核对错误密码、过期授权、停用账号、跨项目权限和普通密码入口；手机移动网络再检查一次。
5. 审核状态通过工作台和单据列表查看，不要求接收微信通知。

当前没有管理员解绑入口；遇到已绑定其他微信时先记录，不能直接改生产库。这里是微信内网页授权，不承诺桌面扫码登录。
