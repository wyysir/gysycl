# 上线验收清单

这是正式验收标准，不是已完成结果；个人试用进度以[当前试用清单](上线前待办清单-2026-10-28.md)为准，当前8/10。真实识别准确率、合同价、连续使用及部分真机边界尚待确认；自动异机备份和无障碍专项暂缓。

## 1. 识别准确率

准备至少 30 张真实、已脱敏的手写送货单，覆盖所有主要供应商、字迹和表格样式。固定为盲测集，不使用 Mock 结果。

逐字段验收：

- 品名匹配：规范品名或别名匹配准确率 ≥ 95%。
- 数量：数值完全一致 ≥ 95%。
- 单价：数值完全一致 ≥ 95%。
- 行金额：数值完全一致 ≥ 95%。
- 整单总价：数值完全一致 ≥ 95%。
- 日期：日期完全一致 ≥ 95%。
- 所有低置信字段均被标为黄色或红色，提示员工人工复核；按用户确认的现有流程，不增加强制确认或提交门槛。

任一关键字段未达到 95%，不得宣称识别验收通过，应调整 OCR 方案、提示词和图片预处理后重新盲测。

## 2. 主数据匹配

- 完全同名或别名：显示“已匹配”并预选。
- 手写错字或简写：前 3 个候选出现在当前明细下方，相似度可见。
- 相似度 ≥ 92%：允许快速确认，但不能静默归档。
- 65%–92%：高亮为“疑似相近”，必须由员工选择或新建。
- 无相近项：员工确认后一键新建；新记录保留来源单据和原始 OCR 文本。
- 新建原材料时单位必填；名称、规格、单位参与后续比价分组。
- 识别时规格按单位自动填写，例如“5斤”应为数量 5、单位“斤”、规格“斤”；“0.5斤 × 25 = 12.5”不得整段写进规格。自动选择品名候选也按候选单位填写规格。
- 管理员合并重复主数据后，历史单据引用和历史金额不发生改变。

## 3. 对账规则

- 数量×单价与实际行金额不一致，未确认抹零时即便差0.01元仍为严重异常；每行减少0.01–0.99元必须明确确认，修改相关字段后失效。见[抹零说明](line-rounding-2026-10-31/使用与维护.md)。
- 明细合计与原单总价不一致时提醒，不作为严重异常，不用明细合计代替纸上总价。
- 合同价按“项目点 + 供应商 + 原材料 + 规格 + 单位 + 生效日期”匹配。
- 合同价超标属于严重异常，普通通过被阻止。
- 跨供应商比价按规范品名、规格、单位分组，不要求供应商相同。
- 同品同规格同单位价格高于近 30 天全公司中位数 10% 时提醒。
- 同供应商同项目历史均价偏离 10% 时提醒。
- 数量超过历史均值 2 倍时提醒。
- 可比样本少于 3 条时显示“样本不足”，不判定异常。
- 重复图片指纹报严重异常；同供应商同号单据（包括跨日期、跨项目）仅提醒重复，允许提交和普通审核通过。金额、合同价等其他严重异常仍按原规则处理。

## 4. 权限与流程

- 项目采购只能操作所属项目点。
- 项目主管只能审核其负责项目点。
- 财务全公司只读，不能上传、修改或审核。
- 提交、退回、通过与撤回的状态在工作台和单据列表查看；微信模板通知已取消并上线，实号收件不再是验收项。
- 主管修改字段后，审计日志包含修改前后明细值。
- 强制通过必须二次确认并填写原因。
- 已通过单据不可被项目点直接编辑。

## 5. 功能回归

- 1–5 页图片上传、顺序正确、单页不超过 15MB。
- 拍照上传和从相册选择分别提供入口；相册可多选，拍照与相册图片可混合追加，总页数仍不超过 5 页，选择图片后入口保持可用。
- OCR任务失败后保留原图，允许人工录入或主动重试；新任务不自动付费重试，主动重试重新计费。
- 单据保存、提交、退回、修改、再次提交、审核完整闭环。
- 并发修改同一单据时第二个请求返回 409。
- Excel 模板三张工作表可下载。
- 存在错误时批量导入整批不写入，并返回行级错误。
- 导出的三个工作表与数据库金额、明细、异常一致。
- 移动端 390px 宽度无横向页面溢出，底部导航不遮挡主要操作。

## 6. 安全与运维

- 未登录访问业务接口返回 401。
- 越权查看其他项目点单据和图片返回 403。
- 图片存储为私有，签名 URL 有时效。
- 登录失败连续 10 次后限流 15 分钟。
- 生产 `SESSION_SECRET` 已更换，数据库与 OSS 账号使用最小权限。
- `/api/health` 返回数据库正常。
- 扩大使用前按实际范围验收队列积压、识别失败率、5xx和数据库连接数监控告警，不能当作现已全部启用。
- 当前为服务器PostgreSQL及本地图片持久存储；定时异机备份与最新备份恢复演练暂缓，未验收。不把RDS自动备份或OSS归档写成已启用。
# 2026-10-29 明细与基础资料管理补充验收

本轮按用户已确认方案实施。85 项自动化测试、44 项主接口和 10 项补充接口回归通过。手机 390px、电脑 1440px 浏览器操作通过；覆盖卡片六字段、更换/清除/取消、慢搜索防覆盖、保存刷新、页面拆分、项目/员工入口、材料别名备注、启停、单位限制、并发 409、合同与已通过采购历史权限。实测结果与截图见 [本轮报告](catalog-2026-10-29/使用与验证说明.md)。历史批准单只读、跨日期同号只提醒、低置信度只提醒继续执行原确认规则。
