# 查看权限与供应商检索维护

2026-11-02：已部署试用网页并通过公网验证，版本和备份以[发布记录](../releases/2026-11-02-view-permissions.json)为准。当前系统仍用于测试和演示。

## 配置方法

管理员进入「系统设置 → 角色权限」，新建或编辑角色，在「查看范围」分别勾选：

| 选项 | 控制范围 |
| --- | --- |
| 查看本项目其他员工的单据 | 单据列表、详情、待审核、历史、统计及导出的所有权范围 |
| 查看采购单价 | 单据行单价、采购历史及价格矩阵、价差 |
| 查看行金额、税额、总金额及金额统计 | 行金额、合计、税额、采购额与金额统计 |
| 查看本项目合同价 | 合同列表、材料详情中的合同价及初始化接口中的合同 |

保存角色后，在「员工」中为每个项目分别分配角色。同一员工可在多个项目拥有不同角色；同一项目的多项授权取并集。四项查看权限不互相代替，也不会自动授予上传、修改、审核或导出权限。处理他人的单据还需要允许查看他人单据；合同新增、删除需要同时允许维护和查看合同价。

新建空权限角色默认只查看本人在获授权项目的单据，三类价格均隐藏。此前已创建的自定义角色没有新增的四项权限键，因此也按未授权处理；管理员需明确勾选需要开放的查看项。内置员工、主管及财务保留原来的查看范围，管理员仍拥有完整管理权限；如需限制员工查看，须分配自定义角色。

角色修改在服务端下次请求生效，已打开的页面需刷新以更新显示。被隐藏的数据不通过普通接口或Excel返回，金额显示「未授权」，不显示为零。以前已经查看或下载的数据不能被远程收回。

## 附件、核对依据和编辑

原图可能同时显示采购单价、金额，必须同时允许这两项才可查看。合同价查看权限单独控制。附件接口每次校验单据所有权及权限，并使用私有、不缓存响应，避免权限撤销后继续从应用缓存取得图片。

备注、审核说明、审计原始详情、OCR警告及核对数值可能包含价格和他人信息：四项查看权限不齐时，隐藏这些自由文本及数值，只保留核对标题、级别和通用说明。涉及全公司记录的重复单据、重复图片及公司比价依据对项目员工也隐藏细节，避免暴露无权访问项目的单号、价格。价格分析自身只使用有权查看的单据和字段。

编辑时由服务器保留隐藏的单价、金额、税额、总价及备注，不接受客户端伪造值；仍可修改获授权的非金额字段。修改数量后可能产生算术异常，需要有相应价格权限的人员处理。新行没有历史金额可保留，隐藏项在服务器初始为零，后续应由有权限人员补全；未授权用户不能确认抹零。撤权后不恢复浏览器保存的旧完整明细。

## 供应商候选项闪退修复

问题触发于空白手工单被当作等待识别的单据反复轮询，刷新时重置供应商检索文字。现在无图片的空白手工单不再为等待OCR轮询；识别中的后台刷新保留用户正在输入的关键字。停顿250毫秒后检索，过时响应不覆盖新查询，检索失败显示提示并保留已有候选。

本地浏览器验证输入单字「鲜」后等待4.5秒候选仍在，空白手工单没有额外详情轮询；模拟有图片待识别页面连续两次后台刷新后文字及候选保留。390像素和1440像素权限显示通过，无页面脚本错误。手机宽度模拟不等同用户真机验收。

## 验证、部署与回退

本地20个测试文件、176项测试通过，其中6组查看权限专项覆盖列表、详情、图片、合同、初始化、历史、统计、Excel、伪造金额、撤权及跨项目隔离。类型检查、本地及服务器生产构建通过，公网24个权限开关、单字候选等待4.5秒保持及无横向溢出验证通过。生产容器对现有数据使用合成受限授权完成只读服务校验，未改变真实账号权限。临时测试账号、角色和单据仅创建在本地，验证后已清除。

本次没有数据库结构变更，四项权限使用现有CustomRole JSON；不重置数据库，不重新导入演示数据，不调用收费识别。部署前核对OCR队列、备份数据库和图片并验证摘要及压缩包可读性，比较19张业务表全部字段与图片指纹。

上一镜像虽支持自定义角色，却不识别新的查看限制，直接回退可能重新暴露数据。回退前必须隔离使用受限自定义角色的账号；优先前向修复。禁止自动改写角色权限、恢复整库或删除业务数据来完成回退。数据库恢复需独立依据和授权。只有本地Git，无远程仓库。
