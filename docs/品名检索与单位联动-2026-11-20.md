# 品名检索与单位联动（v1.1.1）

2026-11-20 用户确认按 HTML 评估方案实施，16:44 已上线。单据明细及批量核对共用此规则。

## 使用

1. 直接在品名框输入，按已有品名或登记别名检索。候选显示规范品名、规格及全部采购单位；同名不同规格分开显示。点击候选或按 Enter 明确选择，输入相近名字不会自动选第一项。原“更换材料”弹窗入口移除；新建品名和权限规则保留。
2. 原单单位为空且资料只有一种采购单位时，自动带入，标注“资料带入”；默认斤的资料另标“暂用单位”。对照原图后点“确认单位”，保存草稿。不会因关联成功提高 OCR 置信度。
3. 同品名多单位时，从单位下拉选择对应采购单位；系统关联该单位的采购资料 ID。原单已有不同单位时先保留，变更单位需明确确认；数量、单价、金额不变，不做自动换算。原单单位未登记可保留品名并保存草稿，单位异常会阻止正常提交；不能直接冒用另一单位采购资料。
4. 改写品名清除旧关联，仅清除此前未确认的资料自动单位；OCR 和手工确认单位保留。改规格不会通过单位选择偷偷恢复旧规格。单位修改不要求重新检索同一品名。
5. 旧草稿在更多单据操作中点“重新比对”；批量卡片也有入口。若有未保存修改，先保存再比对。不重新调用 OCR，不产生识别费用；仅对未关联行作确定匹配，已关联行和已审核单据不自动重写。单位问题独立显示，模糊品名和规格歧义仍需人工选择。

## 下游边界

- 合同价与历史价格仍按具体采购资料、真实规格和实际单位校验，不按同名跨箱/瓶/斤套价。金额勾稽、角色权限、版本冲突、审核流程和本地草稿恢复继续生效。
- 原始 OCR 单位保存在服务端 JSON，客户端不能覆盖；品名候选不返回价格。单位确认文字按权限隐藏价格和金额。
- 未确认单位、重复采购资料和失效候选不会静默选第一个。停用资料不出新候选，未改变的历史关联可继续保留。选择不会自动新增全局别名。
- 数量换算、整批重新整理单位、默认斤核实仍是后续工作。本次不建立新换算关系，不补写已审核历史快照。人工选择单位相当于纠正原单，不代表完成数量换算。
