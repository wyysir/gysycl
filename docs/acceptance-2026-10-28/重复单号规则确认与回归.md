# 重复单号规则确认与回归

日期：2026-10-28。

用户确认：同供应商、同单号跨日期，只提醒重复，可以提交和审核。

- 已删除查重查询中的日期范围限制；跨日期、跨年、跨项目均按供应商与单号检测。
- 提醒级别保留为 WARNING，允许提交并由本项目主管普通审核通过，不需要因单号重复填写强制通过原因。
- 单号为空、供应商未确认、不同供应商同号或仅当前单据自身，不产生此类重复提醒。
- 重复图片、金额不符、合同价超标等其他严重异常仍按原规则处理。
- 已通过单据的历史审批和已关闭检查结果保留；未审核单据在保存、重比对、提交或审核时应用新规则。
