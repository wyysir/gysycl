# 单据新增采购单位与后台手动换算（v1.1.2）

2026-11-20 用户要求直接输入原单单位时为品名建立新单位，并明确由自己在后台找到多单位资料、手动设置比例。本版本按此流程实施，替代 v1.1.1 中“未登记单位需先在后台新建”的操作要求。

## 使用

1. 在单据品名框选中正确品名及规格。单位下拉选“其他／输入原单单位”，输入只、箱、包等真实采购单位。已有但未登记的识别单位，可点“确认原单为…，保存时新增”。
2. 点保存草稿，或在批量核对卡片保存修改。保存成功时新增此品名、此规格的采购单位并关联；已有单位复用，不在打字、自动识别或重新比对过程中新增。重复保存或多行相同单位不重复建档。
3. 打开原材料页面，单位维护选择“同品名同规格多单位”或“多单位待换算”。该筛选以启用的采购单位为准，不把不同规格算成同一款多单位。
4. 编辑对应单位 → 配置原材料归并与换算，填写统一统计单位、商品基准单位及各采购单位比例。例：统计用l、商品基准用瓶，500ml商品1瓶=0.5l，1箱=12瓶；只按实际依据填写。后台会显示同款的采购单位，分别确认每个单位比例。
5. 未设置比例时，采购金额可记录和汇总，统一数量和均价显示待换算；不会把箱、只、斤混合相加，也不把未知数量当0。单位资料已登记后，缺少换算只作提醒，不独立阻止单据正常提交/审核；其他供应商、金额、权限和审核校验继续执行。
6. 设置比例后，新审核的单据冻结当时换算。需要补算旧报表时，管理员在各单位配置中明确勾选“确认用于…尚无已确认换算的历史明细”。已有确认快照不覆盖，原始数量、单价和金额不改；未勾选时历史结果不会静默变化。

## 数据及权限

新增的是采购单位资料，同名同规格仍归同一商品，不是把“只”和“斤”当不同统计原材料。有既定商品归属时沿用；原组尚未归并时仅建立共同归属，并关联该组未归并采购资料，统计单位和换算比例保持待确认。不同规格分开，不按相似名称自动归并。已有单位的价格、合同价或换算比例不复制给新单位；默认斤资料保留其暂用标记，不覆盖真实原单单位。

只有来源项目有新建基础资料权限且可编辑该单据的人可以新增单位；已停用的同单位要求核实启用，不自动启用或另建重复记录。组或规格变化提示重新选择。服务端校验、唯一约束、组锁和单据版本锁共同去重；登记与单据保存同一事务，任一行无效时整批撤销，不留下孤立单位。保留原OCR、识别置信度、金额查看权限及人工抹零确认；不从输入内容自动学习全局别名。

## 验证与发布

43文件373项全量测试通过，最终单位输入及界面修正后追加2文件19项回归、类型检查通过。包括并发去重、失败事务、停用保护、规格区分、隐藏金额、抹零确认、未知换算正常审核及管理员明确补算历史。以正式v1.1.1运行源码施加本次差异构建；未整体部署旧OCR实验，OCR引擎未修改。

最终候选及公网1440/390/320验收通过，覆盖详情/批量核对输入保存、重复复用、后台筛选和手动比例。浏览器写请求全部拦截为虚拟资料；真实后台只读核验。部署前后25表完整指纹一致，没有替用户新增实际单位、修改草稿或设置比例。无数据库迁移或新业务备份；候选容器与临时私有环境已清除，微信验证TXT的HTTP/HTTPS内容不变。

当前用户已确认过但尚未建档的原单位，刷新页面后保存对应单据即可登记；未确认的识别单位先按原单确认。默认斤整体核实仍未替用户完成。
