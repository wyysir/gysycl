# 界面整理、员工账号删除与材料查询（2026-11-03）

## 使用

- 系统设置首页只有项目点、员工账号、角色权限、企业品牌四类选择，点击后弹窗配置。A暖棕配色和B校对编辑弹窗继续使用；项目AGENTS.md已记录此后沿用该交互规则。
- 管理员进入员工账号，点击“删除账号”，二次确认后从列表移除并立即拒绝登录和旧会话访问。数据库逻辑删除，历史单据、营业额、审核及审计保留；不能删除当前登录账号，已删除员工号不能复用。重置密码也改用弹窗。
- 单据中心搜索支持原材料录入名、识别原名、匹配材料名及别名，与项目、日期和状态筛选组合。继续受项目及他人单据查看权限限制。列表有原图缩略图，点击进入原图与明细；未授权价格的员工不返回图片地址。
- 校对明细顶部提供缩略图和“查看原图”；图片加载失败可以重试，无需触发重新识别。保持每行直接点数量、单价、金额打开编辑，未增加常驻大图片区挤占明细。

## 图片核查边界

用户指定系统管理员、妇保院草稿。部署前现场读取当前数据库引用的11个原图/处理图均200，指定草稿及其他现存原图在Edge 1440/390可显示。早期迁移清单包含用户后来删除的引用，不作为恢复数据依据；未复现一个持续的OSS读取故障。此次改善图片入口、错误提示和重试，不声称找到了所有历史网络故障原因，也不恢复用户已删除的单据或图片。
