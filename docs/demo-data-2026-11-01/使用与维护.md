## 可重复执行的维护脚本

先确认目标数据库、备份并安装依赖。以下命令读取当前环境和项目 `.env`；没有 `DATABASE_URL` 时使用本地开发库，不会连接试用服务器。

```powershell
npm run seed:test-data                 # 只预览主数据缺项
npm run seed:test-data -- --apply       # 添加缺少的测试主数据
npm run seed:test-purchases            # 只预览演示采购数据
npm run seed:test-purchases -- --apply  # 添加演示采购与合同价
```

脚本不会被启动流程自动调用。主数据按项目编码、供应商名称、材料规范品名+规格+单位判重，已有记录不覆盖、不启用、不改备注。采购脚本要求5个测试项目及15家测试供应商属于本批次且仍启用，可复用相同规格单位的已有材料；材料停用则整批取消。项目/供应商/材料被人工改名、合并或停用后，先人工确认，不应强行重建依赖。

采购单据按固定批次ID判重；存在同号其他单据时整批取消；已有同项目/供应商/材料的合同不补写另一条重叠演示价。网页已经删除且有 `document.deleted` 审计的演示单据会计入 `skippedDeleted`，不会重新创建。已编辑的现存演示单据也不会被重置。两个脚本均使用事务，失败整体回滚，只有实际新增才写批次审计。

批次为 `test-master-20261101`、`test-purchases-20261101`，新记录ID前缀为 `test_master_20261101_`。没有生成图片、OCR任务、通知、用户或成员授权。
