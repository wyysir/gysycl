## 运行与配置

部署根目录 `/opt/delivery-audit`，源码位于 `app`；使用独立的 `app/deploy/compose.trial.yml`，项目名 `delivery`。Web 和 Worker 使用同一个镜像 `delivery-audit:trial`。PostgreSQL 17、Redis 7、图片分别使用持久卷。

对公网提供 80/443，Nginx 将应用转发至 `127.0.0.1:3000`；PostgreSQL、Redis 不映射公网端口。访问日志省略查询参数，避免记录上传签名。生产会话保持 Secure Cookie。

云密钥与随机会话/数据库配置保存在服务器根目录的 `.env`，管理员创建信息保存在 `admin.private.env`；目录仅 root 可访问，私密文件权限 600。不在文档、报告或知识库记录真实密钥和密码。

重新填写云配置可以运行：

```bash
python3 /opt/delivery-audit/app/deploy/configure-trial.py
```

该脚本保留已有数据库密码和会话密钥；填完后需要重新创建应用和 Worker 容器使配置生效。已有管理员不会通过该脚本自动改密码。
