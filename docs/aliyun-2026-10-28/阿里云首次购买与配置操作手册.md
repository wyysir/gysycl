# 阿里云首次购买与配置操作手册（食安链 · 送货单识别系统）

日期：2026 年 10 月 28 日
适用：第一次购买云服务器、第一次上线本项目的操作人
适用范围：只覆盖"买什么、在哪里点、填什么值"，不包含应用部署命令（部署命令见 `docs/deployment.md`）

---

## 0. 先看这四条，它们会改变你的决策

### 0.1 ⚠️ 项目默认的大模型已经下线，必须换

项目配置文件里写的是 `QWEN_VL_MODEL=qwen-vl-max-latest`。阿里云官方公告（2026-10-10）已把 `qwen-vl-max`、`qwen-vl-plus` 整条老视觉模型线下线，现在调用会直接报错。

**必须改成 Qwen3.6 系列**，推荐两个候选（控制台实测价，2026-10-28）：

| 模型名 | 输入价 | 输出价 | 怎么选 |
| --- | --- | --- | --- |
| `qwen3.6-plus` | 约 ¥3.75 / 百万 Token | 约 ¥22.5 / 百万 Token | 识别准确率优先，先拿它做 30 张真单盲测 |
| `qwen3.6-flash` | 约 ¥1.2–1.87 / 百万 Token | 约 ¥7.2 / 百万 Token | 成本优先，准确率达标后用它省钱 |

> 不要直接信本文档里的价格数字。下单前到「百炼控制台 → 模型广场」搜这两个名字，看你自己账号、自己地域显示的实际单价和是否有免费额度。

### 0.2 域名备案是最长的一条路，必须第一步就启动

在中国内地服务器上对外提供服务，**必须先完成 ICP 备案**，否则阿里云会直接阻断访问。

- 阿里云初审：1 个工作日
- 工信部短信核验：24 小时内要完成
- 管局审核：**1–20 个工作日**

也就是说：**备案可能要等一个月**。而备案的前置条件是"已经有一台包年包月 ≥3 个月、且买了公网带宽的 ECS"。所以正确顺序是：注册域名 → 买 ECS → 立刻提交备案 → **在等备案的这一个月里，用 IP 地址在服务器上把系统部署好、测好** → 备案下来后解析域名 + 配证书 → 上线。

### 0.3 建议分两批买，不要一次买齐

第一批只买"能上线跑起来"的最小集合，跑 1–2 个月后拿真实用量再补第二批。原因：OCR 和模型的费用完全取决于真实单量和图片大小，现在算出来的都是估算，买多必浪费（资源包通常不退）。

### 0.4 地域建议统一选「华东 1（杭州）」

项目里 OCR 默认地址写的是 `ocr-api.cn-hangzhou.aliyuncs.com`，OSS 默认 `oss-cn-hangzhou`。选杭州可以**几乎不用改配置**。如果你坚持选华东 2（上海），就要把这两个地址一起改成上海，且 OCR 和 OSS 必须和 ECS 同地域。

## 1. 买什么：选型结论

### 1.1 第一批（现在就买，够上线）

| 序号 | 产品 | 具体规格 | 为什么这么选 |
| --- | --- | --- | --- |
| 1 | 域名 | `.com` 或 `.cn`，1 个 | 必须和公司备案主体同名 |
| 2 | ECS 云服务器 | 通用算力型 u1，**4 vCPU / 8 GiB**，80GB 系统盘，按使用流量（峰值 100 Mbps） | 见下方"为什么不买 2 核 4G" |
| 3 | ICP 备案 | 免费，必须做 | 内地服务器强制 |
| 4 | SSL 证书 | 先用 certbot 免费版，或买 ¥68/年 的 DV 正式证书 | 见 §4 |
| 5 | OSS 对象存储 | 标准存储，私有 Bucket，杭州，按量付费 | 存送货单原图，不用预付 |
| 6 | RAM 子账号 | 1 个，只给 OCR + OSS 权限 | **绝不能用主账号密钥** |
| 7 | 阿里云 OCR | 开通"表格识别"，按量付费，先充 ¥200 | 项目调用的是 `RecognizeTableOcr` |
| 8 | 百炼（DashScope） | 开通 + 建 API Key，先充 ¥200 | 视觉结构化识别 |

**第一批不买**：云数据库 RDS、云 Redis、负载均衡 ALB、WAF、NAT 网关、弹性公网 IP、日志服务 SLS。理由见 §1.3。

### 1.2 为什么不买 2 核 4G（README 里写的）

这台机器上会同时跑 5 个东西：Web 应用（约 500MB）+ OCR 任务进程（约 500MB）+ PostgreSQL（约 800MB）+ Redis（约 150MB）+ Nginx，加起来约 2GB 常驻。更要命的是**构建阶段**：Next.js 打包 + sharp 图片库 + Prisma 引擎编译，内存峰值能冲到 2–3GB。2 核 4G 在构建和多人同时上传时很容易内存不足直接被系统杀掉。4 核 8G 是安全线，多花的钱（一年几百元）远低于上线失败的成本。

另外，实例族要选 **通用算力型 u1（独享型）**，不要选经济型 e（共享型）。e 实例是共享 CPU、有性能上限，生产环境跑业务会忽快忽慢。

### 1.3 为什么不先买云数据库和云 Redis

本项目用 Docker 一键就能把数据库和 Redis 装在 ECS 里（`docker-compose.yml` 已经配好了）。先不买托管版能省下每月 1000 元以上，也少两个需要配置和维护的东西。

**代价要清楚**：数据库和 ECS 在同一台机器上，机器挂了数据库一起挂；备份要靠自己定时导出（部署脚本 `deploy/deploy.sh` 每次更新前会自动备份，`docs/deployment.md` §7 有每日备份定时任务）。

**什么时候该补买**：日单量稳定超过 300 单、或者数据库 CPU 长期超过 70%、或者公司要求"数据库必须有专业备份和自动故障切换"时，再迁移到 RDS PostgreSQL（2 核 4G 高可用版）+ 云 Redis 1GB。

### 1.4 阿里云"99 计划"的特价机能不能买

活动页：<https://www.aliyun.com/daily-act/ecs/99program>（官方名"99 元，买到的不只是一台云服务器"）

| 99 计划机型 | 配置 | 价格 | 能否用于本项目 |
| --- | --- | --- | --- |
| 经济型 e 实例 | 2 核 2G / 3M 固定带宽 / 40G 盘 | ¥99/年 | **不能**。2G 内存，Docker 构建阶段就会崩 |
| 通用算力型 u1（企业专享） | 2 核 4G / 5M 固定带宽 / 80G 盘 | ¥199/年 | **不建议**。内存勉强够常驻，但构建和多并发时 OOM 风险高；5M 固定带宽上传一张 15MB 图要约 24 秒 |
| 4 核 8G 标准款 | 4 核 8G | 约 ¥955/年 | **可以**，但要先确认带宽模式，固定 1–5M 的话上传体验差 |

**结论**：99 元和 199 元这两台只适合"买来练手、熟悉 Linux 和部署流程"，**不能作为正式上线的生产机**。原因是两条硬伤：

1. **内存不够**：本项目常驻就要约 2GB（Web + OCR 任务进程 + PostgreSQL + Redis + Nginx），而 Next.js 构建时内存峰值能到 2–3GB。2G 必崩，4G 也悬。
2. **固定带宽卡上传**：这两款都是固定带宽套餐（3M / 5M），**不能改成按使用流量 + 拉满峰值**。项目点员工用手机拍送货单上传，5M 带宽传 15MB 图片要 20 多秒，体验很差。

**但这两台有购买价值**：价格锁定到 2029 年 3 月 31 日、续费不涨价，限购 1 台。花 99 元买一台当"练习机"，在上面练部署、跑通流程、做 30 张真单盲测，不会因为操作失误影响正式环境。而且企业认证主体可以同时保有 1 台 e 实例 + 1 台 u1 实例，不影响你另外再买正式机。

**正式机推荐（按性价比排序）**：

| 排序 | 配置 | 价格 | 说明 |
| --- | --- | --- | --- |
| 1 | 4 核 8G / **200M 峰值带宽（按流量）** / 70G ESSD | 约 ¥1,159/年 | 带宽模式最适合本项目，上传快 |
| 2 | 4 核 16G / 10M 固定带宽 / 100G ESSD | ¥89/月（约 ¥1,068/年） | 内存翻倍更稳，但带宽偏小 |
| 3 | 99 计划的 4 核 8G 标准款 | 约 ¥955/年 | 下单前确认带宽是不是固定的 |

活动选型入口：<https://www.aliyun.com/daily-act/ecs/activity_selection>；优惠券和权益：<https://www.aliyun.com/benefit>

> 价格与库存随时变，且活动价通常不能和优惠券叠加、续费规则各不相同。下单前把配置页截图保存。

## 2. 购买顺序（照着这个顺序走，不要乱）

```
第 1 步  注册阿里云账号 + 企业实名认证      （半天）
第 2 步  注册域名 + 域名实名认证            （1 天，认证后才能备案）
第 3 步  购买 ECS（包年包月 1 年）          （10 分钟）
第 4 步  立刻提交 ICP 备案  ────────────┐
                                        │
第 5 步  创建 OSS Bucket                │  等备案的空档期（1–20 个工作日）
第 6 步  创建 RAM 子账号 + 密钥           │  在服务器上用 IP 地址把系统
第 7 步  开通阿里云 OCR + 百炼            │  部署好、测通、跑 30 张真单盲测
第 8 步  在服务器上部署（用 IP 访问）      │
                                        │
第 9 步  备案通过 ←───────────────────────┘
第 10 步 域名解析到 ECS 公网 IP
第 11 步 申请并部署 SSL 证书
第 12 步 正式对外上线 + 微信服务号接入
```

关键在于：**第 4 步一做完就提交备案，备案是别人在审，你不用等它，这段时间正好用来部署和测试。**

## 3. 每一步的具体操作

### 第 1 步 · 账号与实名认证

1. 打开 <https://www.aliyun.com> → 注册账号。
2. **用公司主体注册，并完成企业实名认证**（控制台右上角头像 → 实名认证 → 企业认证）。需要营业执照、法人姓名身份证号、对公账户验证。
3. 重要：后续备案主体、域名所有者、微信公众号主体，**三者必须是同一家公司**，否则备案会被打回。
4. 开启多因素认证（MFA）：头像 → 安全设置 → 绑定 MFA。

### 第 2 步 · 注册域名

1. 打开 <https://wanwang.aliyun.com> → 搜索想要的域名（建议公司名拼音缩写 + `delivery`，例如 `gsdelivery.com`）。
2. 加购 → 结算。
3. 注册完成后，必须做**域名实名认证**（控制台 → 域名 → 域名列表 → 未实名认证模板 → 提交资料）。域名实名认证通过后，通常还要等 1–2 天同步，才能用于备案。
4. 参考价格：`.com` 首年约 ¥60–100，续费约 ¥80–120/年。

### 第 3 步 · 购买 ECS（重点，逐项照选）

入口：<https://www.aliyun.com/product/ecs> → 「立即购买」→ 选「自定义购买」

| 页面上的选项 | 你选什么 | 注意 |
| --- | --- | --- |
| 付费类型 | **包年包月** | 必须。按量付费不能用于备案 |
| 购买时长 | **1 年** | 备案要求 ≥3 个月；1 年单价最划算 |
| 地域 | **华东 1（杭州）** | 必须中国内地，否则不能备案 |
| 可用区 | 默认（随机分配） | 不用改 |
| 实例规格族 | **通用算力型 u1** | 在筛选里找"通用算力型"，型号 `ecs.u1-c1m2.xlarge` |
| CPU / 内存 | **4 vCPU / 8 GiB** | 别选 2 核 4G |
| 镜像 | **Alibaba Cloud Linux 3.2104** 或 **Ubuntu 24.04 LTS 64 位** | 两个都行，脚本支持；选 Linux 不要选 Windows |
| 系统盘 | **ESSD Entry（或 ESSD PL0）80 GiB** | 40GB 偏小，Docker 镜像和构建缓存会吃空间 |
| 公网 IP | **勾选「分配公网 IPv4 地址」** | 不勾不能备案，也访问不了 |
| 带宽计费模式 | **按使用流量计费** | 见下方说明 |
| 带宽峰值 | **拉到最大（100 Mbps）** | 按流量计费时，峰值拉满不额外收费，只按实际流量算 |
| 安全组 | 新建，放行 **22 / 80 / 443** | 22 端口建议把"授权对象"改成你公司的固定 IP |
| 登录凭证 | **密钥对**（推荐）或自定义 root 密码 | 新手也可以先用控制台自带的"远程连接"，见下 |

**为什么带宽要选"按使用流量"**：固定带宽模式下，上传速度会被你买的带宽卡住 —— 买 5 Mbps 的话，上传一张 15MB 的送货单照片要 20 多秒，项目点员工会疯。改成按使用流量后，带宽峰值可以拉到 100 Mbps，上传飞快，而内部系统每月实际流量很小，流量费通常只要几十元。

5. 右侧确认金额 → 下单支付。
6. 买完后到「ECS 控制台 → 实例」记下**公网 IP**，并把实例名改成 `delivery-prod` 方便认。

**怎么连上服务器**（第一次买的人推荐这个，不用配密钥）：
ECS 控制台 → 实例列表 → 右侧「远程连接」→「通过 Workbench 远程连接」→ 免密登录。浏览器里直接弹出命令行终端，可以直接粘贴命令。
后续想用 PowerShell 连：`ssh root@你的公网IP`。

### 第 4 步 · 提交 ICP 备案

1. 打开 <https://beian.aliyun.com> → 「开始备案」。

**先决定用哪个主体备案（企业 / 个人）——本项目必须选企业，见下表：**

| 对比项 | 企业备案 | 个人备案 |
| --- | --- | --- |
| 需要材料 | 营业执照、法人身份证、**网站负责人身份证 + 人脸核验** | 本人身份证 + 人脸核验 |
| 域名所有者 | 必须是**同一家公司**的名义持有 | 必须是**本人**名义持有 |
| 允许的网站内容 | 企业内部系统、业务系统都可以 | **只能是个人性质的非经营性内容**，放公司内部系统会因"超出个人范围"被打回 |
| 微信服务号 | 可认证服务号，能做网页授权和模板消息 | 个人订阅号无法微信认证，**本项目微信登录直接不可用** |
| 审核时长 | 材料多，初审可能打回一次，总时长 1–20 个工作日 | 材料少，但管局对内容审查更严 |
| 阿里云账号要求 | 建议做**企业实名认证**（199 元 u1 机型也要求企业认证） | 个人实名即可 |

> 结论：**本项目必须走企业备案**。三个主体必须一致 —— 备案主体（公司）、域名所有者（同一家公司）、微信公众号主体（同一家公司），任何一个对不上都会被管局打回。
>
> 常见坑：域名已经用个人名义实名认证了怎么办？先在域名控制台做「域名信息修改（过户）」，把所有者改成公司，等实名认证通过后再提交企业备案。

2. 按向导填：主体信息（公司）、网站信息（域名、网站名称、服务类型选"其他"）、上传资料（营业执照、法人身份证、网站负责人身份证 + 人脸核验）。
3. 网站名称建议填「食安链送货单管理系统」，**不要出现"中国""网""论坛""商城"等敏感词**，容易被打回。
4. 提交后保持手机畅通：
   - 阿里云初审（1 个工作日）会有客服电话核对；
   - 初审通过后收到工信部短信，**必须在 24 小时内**到工信部网站完成短信核验；
   - 然后进入管局审核（1–20 个工作日）。
5. 备案期间**服务器可以照常部署和测试**（用 IP 访问），不受影响。

### 第 5 步 · 创建 OSS Bucket（存图片）

1. 打开 OSS 控制台 <https://oss.console.aliyun.com> → 「Bucket 列表」→「创建 Bucket」。
2. 填这些值：

| 选项 | 值 |
| --- | --- |
| Bucket 名称 | 例如 `gs-delivery-prod`（全球唯一，被占了就换一个） |
| 地域 | **华东 1（杭州）** |
| 存储类型 | 标准存储 |
| 读写权限 | **私有** ← 必须，送货单图片不能公开 |
| 冗余类型 | 本地冗余（便宜，够用） |

3. 创建后，进 Bucket →「数据安全 → 跨域设置 CORS」→ 创建规则：

| 字段 | 值 |
| --- | --- |
| 来源 | `https://你的域名`（备案下来后再填，先留空也行） |
| 允许 Methods | `PUT` 和 `GET` |
| 允许 Headers | `Content-Type` |

4. 记下这三个值，后面要填进配置：`OSS_BUCKET`（Bucket 名）、`OSS_REGION`（`oss-cn-hangzhou`）、`OSS_ENDPOINT`（`https://oss-cn-hangzhou.aliyuncs.com`）。

### 第 6 步 · 创建 RAM 子账号（安全必做）

**绝对不要用主账号的 AccessKey 填进配置文件。** 主账号密钥泄露等于公司整个阿里云被人拿走。

1. 打开 <https://ram.console.aliyun.com> →「身份管理 → 用户」→「创建用户」。
2. 访问方式勾选 **「使用永久 AccessKey 访问」**（就是 OpenAPI 调用访问）。
3. 创建后会显示 `AccessKey ID` 和 `AccessKey Secret`，**立刻复制保存**（Secret 只显示这一次）。
4. 给这个用户授权：「权限管理 → 新增授权」，添加系统策略：
   - `AliyunOSSFullAccess`（如果只想限定这一个 Bucket，就用下面的自定义策略替代）
   - `AliyunOCRFullAccess` —— OCR 调用权限
   - **`AliyunBSSContractFullAccess`** —— 账单与开通权限。**这条容易漏**：官方文档明确要求子账号同时有它和 `AliyunOCRFullAccess` 才能开通 OCR 服务，缺了会在控制台开通过程中报权限不足。
5. 更严格的做法（推荐但可选）：写自定义策略，只允许访问这一个 OSS Bucket：

```json
{
  "Version": "1",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["oss:PutObject", "oss:GetObject", "oss:DeleteObject"],
      "Resource": "acs:oss:*:*:gs-delivery-prod/*"
    }
  ]
}
```

### 第 7 步 · 开通阿里云 OCR（表格识别）

1. 打开 **文字识别 OCR 产品页 <https://ai.aliyun.com/ocr>** → 点「开通享免费额度」，会跳到控制台 <https://ocr.console.aliyun.com/overview>。
   > 注意：阿里云 OCR 不叫 `/product/ocr`（该地址已 404），正确入口在 **ai.aliyun.com/ocr**。
2. 本项目调用的接口是 **表格识别（RecognizeTableOcr）**，且开启了手写识别参数（`isHandWriting=true`）。表格识别属于「通用文字识别」这一类，**每一类 OCR 服务要在控制台单独开通**，开通本身不收费。开通后确认"表格识别"在已开通列表里。
3. 计费方式选 **按量付费**（先不要买资源包）。
4. **免费额度**：开通后按服务不同送 **200 次/月** 或 **一次性 50 次**。这 200 次正好够你先把 30 张真单盲测跑完再花钱。免费额度用完后才开始按量扣费，从账号余额扣。
5. 先充 ¥200 到账号余额，或直接确保账号余额充足。
6. 并发限制：每个 OCR 服务默认 **10 QPS**（每秒 10 次）。本项目一次上传最多 5 页、并发不高，默认够用。
5. 计费口径（2026-10-23 核对的官方公开价，月度累进，**下单前请以控制台为准**）：

| 当月累计调用次数 | 单价 |
| --- | --- |
| 前 10,000 次 | ¥0.0825 / 次 |
| 10,001 – 100,000 次 | ¥0.0495 / 次 |
| 100,001 – 500,000 次 | ¥0.0415 / 次 |

> 注意：**每页图片算一次调用**。一单 3 页就是 3 次。识别失败重试也会扣费。

6. **先用真实单据测出单页成功率再决定要不要买资源包**。资源包通常不退不换，不要一上来就买 10 万次。

### 第 8 步 · 开通百炼并拿 API Key（最容易踩坑的一步）

1. 打开 <https://bailian.console.aliyun.com> → 用同一个阿里云账号登录 → 开通服务。
2. 右上角头像 →「API Key」→「创建新的 API Key」→ 复制保存（这就是 `DASHSCOPE_API_KEY`）。
3. **确认模型可用**：左侧「模型广场」搜索 `qwen3.6-plus` 和 `qwen3.6-flash`，点进去看：
   - 你的地域是否有售（建议和 ECS 一样选华东 1 杭州；杭州没有就选北京）
   - 实际单价和是否有免费额度
   - 模型详情页里有「API 示例」，确认支持图片输入 + JSON 结构化输出
4. 充值：百炼默认可能走后付费，保险起见在控制台充 ¥200–500。
5. 设置用量告警：控制台里找「用量与成本」，设置月度预算提醒（例如 ¥500 提醒一次、¥1000 再提醒一次），防止异常调用烧钱。

### 第 9–11 步 · 备案通过后

1. **域名解析**：域名控制台 → 解析设置 → 添加 A 记录，主机记录填 `delivery`（或你想要的二级域名），记录值填 ECS 的**公网 IP**。
2. **验证解析**：在本机 PowerShell 执行 `nslookup delivery.你的域名.com`，看到你的 IP 就成了。
3. **SSL 证书**，两个方案二选一（见 §4）。
4. 部署完成后访问 `https://你的域名/api/health`，返回 `{"ok":true,"database":"up"}` 就是通了。

## 4. HTTPS 证书怎么选

| 方案 | 价格 | 有效期 | 适合谁 |
| --- | --- | --- | --- |
| **certbot（Let's Encrypt）** | ¥0 | 90 天，服务器自动续期 | 推荐第一次用。项目脚本 `deploy/server-bootstrap.sh` 已经装好了 certbot，一条命令签发 |
| 阿里云个人测试证书（免费版） | ¥0 | 3 个月，每个主体每年限 20 张，**到期要手动重新申请并替换** | 不推荐：3 个月要手动换一次，容易忘，忘了全公司访问不了 |
| 个人测试证书 Pro 版 | ¥34/张 | 6 个月 | 同上，仍需手动换 |
| **正式 DV 单域名证书** | 约 **¥68/年** | 12 个月 | **推荐**：一年只管一次，企业内部系统够用 |
| OV 企业型证书 | 约 ¥238–1,900/年 | 12 个月 | 证书里能显示公司名，需要提交营业执照人工审核 |

**我的建议**：如果不想在服务器上折腾，**直接在阿里云买 ¥68/年的 DV 单域名正式证书**，一年换一次，最省心。

购买与部署路径（阿里云证书）：
1. <https://www.aliyun.com/product/cas> → 购买 → 选「DV 单域名」→ 1 年。
2. 进入「数字证书管理服务控制台」→「SSL 证书管理」→「正式证书」→ 找到刚买的证书 →「申请证书」→ 填域名 → 域名验证方式选 **DNS 验证**（后台会自动加一条 TXT 解析记录，最省事）。
3. 签发后 →「下载」→ 服务器类型选 **Nginx** → 下载到本机，得到两个文件：`xxx.pem`（证书）和 `xxx.key`（私钥）。
4. 上传到服务器，例如放到 `/etc/nginx/certs/`，然后改 Nginx 配置里这两行：

```nginx
ssl_certificate     /etc/nginx/certs/xxx.pem;
ssl_certificate_key /etc/nginx/certs/xxx.key;
```

5. `nginx -t && systemctl reload nginx` 生效。

如果选 certbot（免费），服务器上就两条命令：

```bash
certbot --nginx -d 你的域名 --agree-tos -m 你的邮箱 --redirect
certbot renew --dry-run    # 验证自动续期是否正常
```

## 5. 买完之后：这些值填到哪里

把买到的东西对应填进服务器上的 `/opt/delivery-audit/.env`（模板：`deploy/env.production.example`，权限设 `chmod 600`）：

| 环境变量 | 填什么 | 从哪来 |
| --- | --- | --- |
| `APP_URL` | `https://你的域名` | 必须和最终访问地址完全一致，结尾不带斜杠 |
| `SESSION_SECRET` | `openssl rand -base64 48` 生成 | 服务器执行这条命令，不要自己编 |
| `POSTGRES_PASSWORD` | `openssl rand -base64 24` 生成 | 同上 |
| `DEMO_MODE` | `false` | 生产必须 false，true 会写入演示假数据 |
| `OCR_MODE` | `aliyun` | 试运行阶段可先 `mock` |
| `ALIYUN_ACCESS_KEY_ID` / `SECRET` | RAM 子账号的密钥 | 第 6 步 |
| `ALIYUN_OCR_ENDPOINT` | `ocr-api.cn-hangzhou.aliyuncs.com` | 杭州地域保持默认 |
| `DASHSCOPE_API_KEY` | 百炼 API Key | 第 8 步 |
| `DASHSCOPE_BASE_URL` | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 保持默认 |
| **`QWEN_VL_MODEL`** | **`qwen3.6-plus`** ← 必须改 | **原来的 `qwen-vl-max-latest` 已下线！** |
| `STORAGE_DRIVER` | `oss` | |
| `OSS_REGION` / `OSS_BUCKET` / `OSS_ENDPOINT` | 见第 5 步 | |
| `OSS_ACCESS_KEY_ID` / `SECRET` | RAM 子账号密钥 | 可以和 OCR 用同一个子账号 |

改完后重启容器生效：

```bash
cd /opt/delivery-audit/app
docker compose --env-file /opt/delivery-audit/.env -p delivery \
  -f docker-compose.yml -f docker-compose.override.yml up -d app worker
```

**验证识别链路真的通了**：上传一张真实送货单，然后看任务进程日志：

```bash
docker compose -p delivery logs -f worker
```

- 看到正常返回结构 → 模型选对了；
- 报 `model not found` / `invalid model` → 模型名不对，回到第 8 步在模型广场确认；
- 报 OCR 权限或欠费 → 检查 RAM 子账号权限和账号余额。

## 7. 首次购买最容易踩的 8 个坑

| # | 坑 | 后果 | 怎么避 |
| --- | --- | --- | --- |
| 1 | ECS 买了按量付费 | 不能备案，备案要重来 | 必须包年包月 ≥3 个月 |
| 2 | 忘了勾选公网 IP / 没买带宽 | 不能备案，外网访问不了 | 购买页勾「分配公网 IPv4 地址」 |
| 3 | 选了经济型 e 实例 | 共享 CPU，高峰期卡顿 | 选通用算力型 u1 |
| 4 | 固定带宽买小了 | 员工上传一张图等 20 秒 | 改按使用流量 + 峰值拉满 |
| 5 | 用了主账号 AccessKey 填配置 | 密钥泄露 = 整个阿里云失守 | 必须建 RAM 子账号 |
| 6 | OSS Bucket 设成公共读 | 送货单图片任何人可下载 | Bucket 读写权限设「私有」 |
| 7 | 没在安全组放行 80/443 | 网站打不开，还以为部署失败 | ECS 控制台 → 安全组 → 放行 80、443（**不要放行 3000/5432/6379**） |
| 8 | 沿用 `qwen-vl-max-latest` | 模型已下线，识别全线失败 | 改成 `qwen3.6-plus` 并在控制台确认可用 |
