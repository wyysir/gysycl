# 品牌台账：确认方案与实际界面对照

日期：2026-10-30。依据为同目录 `品牌台账-原方案基线.md` 中已确认的金棕色方案及五张参考图。早期蓝色稿、已废弃的独立方案不是实施依据。本文件记录落实情况，不重新提出一套设计。

## 对照原则

- 配色、字体、尺寸、状态以确认方案的文字规范为准；样图中的演示金额、供应商、日期不写死进业务页面。
- 使用既有企业 Logo 原图和品牌接口，等比展示在白色品牌区域；此次不重新上传相同 Logo，不重绘品牌字。
- 保留实际角色权限、采购口径、数据校验及 B06 恢复机制。录入、核对、审核、分析沿用真实业务 API。
- 以下为运行中的应用截图，数据来自隔离 Mock 演示库。样例原图仅用于检验图片查看，不用它证明识别准确率；没有使用付费 OCR。

## 规范落实位置

`src/app/design.css` 保留权威色值和通用组件；`src/app/ledger.css` 在根布局最后导入，限定上述页面的布局、折叠、抽屉和响应式行为，不引入另一套主题。

- 主色：咖棕 `#775740`、品牌金 `#D0A350`；悬停 `#654832`、按下 `#543B29`。
- 辅助：深金 `#8A651F`、浅金 `#F7EEDB`；页面 `#F7F5F0`、卡片 `#FFFFFF`、侧栏 `#F1ECE3`、线 `#E1D9CC`、输入边框 `#A99A88`、文字 `#383435` / `#6F685E`、禁用底 `#EEEAE3`。
- 成功 `#2D6B4C/#EDF5EE`、提醒 `#8A5700/#FFF4D6`、错误 `#AD3D32/#FBEDE9`。合同超价是严重异常，低 OCR 置信度只是提醒，高置信度使用中性标签。
- 字体栈 `PingFang SC / Microsoft YaHei / system-ui / sans-serif`；统计32/40、电脑标题28/36、手机标题24/32、面板18/26，字重600；电脑正文14/22、手机输入16/24，字重400；按钮和字段标签500；辅助说明12/18。Logo 字体保留在原图内。
- 卡片12px、普通控件10px圆角；电脑输入40px、手机48px；手机返回及更多目标至少44px。金额启用等宽数字、右对齐；通常显示两位小数。单价原业务允许四位小数，因此实际超过两位时保留原精度，不能为了外观截断保存值。
- 按钮包含默认/悬停/按下/聚焦/加载/禁用；输入保留错误/低置信提醒/禁用/只读；卡片、导航、表格、状态标签、抽屉、缩略图状态延续原规范。加载/空数据/失败沿用真实接口反馈。

## 跳转与返回

```text
工作台 / 单据中心
  └─点击录入（有项目权限）→ 录入页
      ├─返回 → 原来源页面；有修改时先进入 B06 离开确认
      └─上传成功 → replace 到单据详情；返回单据中心，不返回已提交上传页

工作台 / 单据中心
  └─点击单据或继续校正 → 单据详情
      ├─返回列表 → 原来源页，恢复已有筛选/页码/滚动
      ├─来源页或原图摘要 → 原图查看层 → 关闭回原位置，输入保留
      ├─保存成功 → 留页；失败 → 保留填写并提示
      └─提交成功 → 单据状态刷新；审核入口按角色/状态显示

审核队列
  └─点击核对并审核 → 主管审核详情
      ├─返回队列 → 恢复队列筛选、选择及滚动
      ├─中屏点击处理依据 → 抽屉 → 关闭/Escape 返回原焦点
      └─退回/强制通过 → 必填原因；强制通过二次确认；失败保留原因

价格分析
  └─矩阵单元或价差材料 → 供应商对照/采购历史面板
      ├─关闭 → 保留筛选与矩阵位置
      └─查看来源单据 → 单据详情 → 返回分析，恢复材料与筛选

以上编辑页的浏览器后退/前进/站内离开
  └─有未保存内容 → 取消留页 / 暂存后离开 / 放弃 / 适用时保存后离开
      └─暂存或保存失败 → 留页；重新进入 → 校验账号、版本、状态后恢复
```

## 验证与重现

- 125项自动化测试、TypeScript、生产构建通过；Chromium/WebKit 各21项 B06 回归通过。
- `scripts/verify-brand-ledger.mjs`：12项界面与交互检查，含五页截图、32/44/48px相关展示、抽屉跨断点滚动释放、金额两位格式/四位单价保留、原图/折叠不丢编辑、上传来源返回、320/390/430宽度溢出检查。
- 脚本只允许 localhost/127.0.0.1，确认 `ocrMode=mock`；使用演示账号。环境变量 `LEDGER_FIXTURE_PATH` 指向本地 JSON（`base,draftId,reviewId`），`LEDGER_OUTPUT_DIR` 指向输出目录。默认文件 `.tmp/ledger-shots/fixture.json` 和两张演示页 `.tmp/ledger-shots/page1.png,page2.png`。
- 视觉夹具需独立库：一个4行2页草稿、一个4行2页待审核单；第一行4.80且有合同错误和低置信提醒；分析有“青菜”采购历史。当前隔离工作目录 `.tmp/ledger-preview-20261030`，端口3237。禁止把离线夹具脚本指向正式库；不要为重现样图更改真实单据。
- B06 回归脚本需使用它自己的隔离目录与端口3236，避免写测试单据影响视觉夹具。
- 真机手势、相机/相册、品牌观感、真实 OCR 准确率仍按 `04-待人工审核清单.md` 验收；模拟器与截图不能代替这些检查。
