# 融合重设计方案｜品牌台账

整体视觉已围绕你提供的Logo调整为：**金色品牌点缀、咖棕操作色、深灰文字、暖白背景**。公司Logo与业务界面采用统一色系，后续上传正式Logo即可放入预留品牌区域。

以下包含三份方案的融合依据、统一规范、**5张高保真样例图**及页面跳转说明。本阶段仅交付设计。

## 一、三份方案如何融合

| 维度 | 原方案中的可取部分 | 最终整合与取舍 |
|---|---|---|
| **配色** | 1号的暖纸层次；2号对操作、识别、异常的区分；3号的大面积留白与克制用色 | 以公司Logo重新建立色板。保留暖白层次，操作统一咖棕，选中态使用浅金。成功、提醒、错误继续使用独立语义色。 |
| **字体** | 1号的等宽金额排版；2号的完整字阶；3号的手机16px正文与输入字号 | 界面统一系统无衬线字体，数字使用等宽数字特性。公司品牌字由Logo原图承载；不另用楷体或专用数字字体，减少设备间差异。 |
| **组件** | 1号的多页缩略图和行级异常；2号的候选匹配与状态分层；3号的固定操作区、来源追溯和明确返回逻辑 | 卡片统一12px圆角，控件统一10px圆角。电脑突出原图对照，手机采用可展开明细；异常始终能定位到对应字段。 |

**设计重点：** 员工录入时知道下一步，主管审核时看到依据，财务比价时理解口径，管理员维护时明确影响范围。

同时纠正旧样图与业务规则不一致的表达：合同超价属于严重异常；低OCR置信度只提醒；待审核单据不能使用草稿删除入口。

## 二、最终视觉与组件规范

### 1. 配色

下面是本轮确定的设计色值。Logo基础色来自所提供JPG的近似取样，取得正式品牌色规范后可校准。

| 分类 | 色值 | 使用范围 |
|---|---|---|
| 主色·品牌金 | `#D0A350` | 品牌点缀、图表条、页码选中标识 |
| 主色·咖棕 | `#775740` | 主按钮、导航选中文字、重要操作 |
| 主操作悬停 / 按下 | `#654832` / `#543B29` | 按钮交互状态 |
| 辅助色·深金 | `#8A651F` | 聚焦描边、重点链接 |
| 辅助色·浅金 | `#F7EEDB` | 选中背景、矩阵相对高值背景 |
| 中性色·页面暖白 | `#F7F5F0` | 页面背景 |
| 中性色·内容白 | `#FFFFFF` | 卡片、表单、Logo品牌区 |
| 中性色·暖灰 | `#F1ECE3` | 侧栏、次级区域 |
| 中性色·描边 | `#E1D9CC` | 卡片与分隔线 |
| 中性色·输入描边 | `#A99A88` | 输入框边界 |
| 中性色·正文深灰 | `#383435` | 标题、正文、金额 |
| 中性色·辅助文字 | `#6F685E` | 标签、日期、来源说明 |
| 中性色·禁用背景 | `#EEEAE3` | 禁用控件、加载占位 |
| 成功文字 / 浅底 | `#2D6B4C` / `#EDF5EE` | 已匹配、已通过 |
| 提醒文字 / 浅底 | `#8A5700` / `#FFF4D6` | 低置信度、一般提醒 |
| 错误文字 / 浅底 | `#AD3D32` / `#FBEDE9` | 严重异常、输入错误、删除确认 |

咖棕底白字的对比度约为 **6.52:1**，因此用于主要按钮。Logo金色用于点缀和浅色层次，不承担小字号白字按钮。

### 2. 字体层级

界面字体统一为：`PingFang SC / Microsoft YaHei / system-ui / sans-serif`。Logo内的字体保留原样。

| 用途 | 字号 | 字重 | 行高 |
|---|---:|---:|---:|
| 关键金额、统计数字 | 32px | 600 | 40px |
| 电脑页面标题 | 28px | 600 | 36px |
| 手机页面标题 | 24px | 600 | 32px |
| 面板标题 | 18px | 600 | 26px |
| 分组标题 | 16px | 600 | 24px |
| 手机正文、输入内容 | 16px | 400 | 24px |
| 电脑正文、表格 | 14px | 400 | 22px |
| 字段标签、按钮 | 电脑14px / 手机16px | 500 | 22px / 24px |
| 时间、来源、辅助说明 | 12px | 400 | 18px |

金额右对齐、统一两位小数；数量保留业务精度。数字启用等宽数字，单位紧邻数值展示。

### 3. 核心组件及状态定义

统一使用4px基础刻度，主要间距为8、12、16、24、32px。电脑常规控件高40px，手机高48px；触控目标至少44×44px。

| 组件 | 基础样式 | 状态定义 |
|---|---|---|
| **按钮** | 圆角10px；主按钮咖棕底白字，次按钮白底咖棕描边 | 默认 `#775740`；悬停 `#654832`；按下 `#543B29`；聚焦为2px深金外框；加载时显示进度图标并防止重复点击；禁用为暖灰底并说明原因。 |
| **输入框** | 白底，圆角10px，标签置于上方，边框 `#A99A88` | 聚焦使用2px深金边框；错误使用红边及字段下方说明；低置信字段用浅黄提示但保持可编辑；只读保留清晰文字；禁用降低对比度。 |
| **卡片** | 白底、12px圆角、1px细边框，内边距16或24px | 可点击卡片悬停加深边框；选中使用浅金底和深金描边；异常标记放在相关字段或卡片标题处；加载显示占位；空状态展示原因及可执行入口。 |
| **导航** | 暖灰侧栏，图标配文字，导航项圆角10px | 当前项为浅金底、咖棕字；悬停轻微加深背景；键盘聚焦显示描边；无权限入口不显示。手机任务页收起全局导航。 |
| **表格 / 单据列表** | 浅暖灰表头、细分隔线，金额右对齐 | 悬停行浅暖灰；选中行浅金；错误字段单独标红；加载显示骨架行；无记录显示“暂无记录”，缺失价格显示“—”，不显示为0。 |
| **状态标签** | 图标加文字，避免只靠颜色判断 | 草稿灰；识别中咖棕配加载图标；待审核赭黄；已通过绿；退回补充红。OCR达到阈值使用中性标签，低于阈值才使用黄色提醒。 |
| **弹窗 / 抽屉** | 白底、12px圆角；手机复杂内容全屏展示 | 打开后焦点进入弹层；确认中阻止重复操作；失败保留填写内容；取消或关闭返回原位置与原焦点；删除确认明确对象、数量和不可恢复后果。 |
| **图片上传 / 页码缩略图** | 编号缩略图、咖棕操作图标 | 选中页深金描边；上传中显示实际状态；失败显示原因和重试入口；达到5页后禁止继续追加并说明限制；移除图片后更新数量。 |

**布局约定：** 电脑侧栏224px；审核页在≥1440px时采用原图、明细、依据三栏；中等宽度采用双栏加依据抽屉；手机使用单栏及两列字段。

## 四、页面跳转、触发条件与返回逻辑

### 主要页面路径

```text
登录 ──[员工号验证成功]──→ 工作台
返回：退出登录回到登录页；有合法登录前目标时，登录后恢复该目标。

工作台 / 单据中心 ──[点击“录入送货单”，且有项目提交权限]──→ 上传页
返回：回到进入上传前的页面；已有选图时先询问是否放弃，取消则留在上传页。

上传页 ──[项目、日期及1–5张图片有效，点击“上传并识别”，建单成功]──→ 单据详情
返回：进入单据中心；已建单不再返回上传页重复创建。

工作台 / 单据中心 ──[点击单据条目或“继续校正”]──→ 单据详情
返回：恢复来源页面的筛选、页码及滚动位置；直接打开链接时默认返回单据中心。

单据详情 ──[点击“查看原图”或来源页]──→ 原图查看层
返回：关闭查看层，回到原明细位置；保留选中的图片页。

工作台 ──[主管或管理员点击“待审核”或“审核队列”]──→ 审核队列
返回：回到工作台。

审核队列 ──[点击待审核单据]──→ 主管审核详情
返回：点击“返回队列”，恢复队列筛选和滚动位置。

工作台 / 导航 ──[点击“价格分析”]──→ 价格分析页
返回：回来源页面；无来源记录时返回工作台。

价格分析 ──[点击矩阵单元格或物料条目]──→ 材料价格与采购历史面板
返回：关闭面板，保留日期、项目、选中材料及矩阵位置。

材料采购历史 ──[点击来源单据“查看”]──→ 单据详情
返回：恢复材料面板及原分析条件；财务查看全过程保持只读。

更多 / 基础资料 ──[点击原材料或供应商与合同]──→ 对应资料页
返回：恢复来源菜单；资料页打开的详情关闭后回原列表。

更多 / 导航 ──[管理员点击“系统设置”]──→ 系统设置
返回：回来源页面；非管理员不显示该入口。
```

### 单据操作后的状态与去向

| 操作 | 触发条件 | 结果与返回 |
|---|---|---|
| 识别结束 | OCR完成或失败 | 留在详情；完成后展示明细，失败保留原图与已有内容，提供人工录入和有权限的重试入口。 |
| 提交审核 | 草稿或退回补充；供应商、明细材料已关联；点击提交 | 原页变为待审核，提交人只读；返回原列表或工作台。低置信度不增加确认门槛。 |
| 普通通过 | 待审核、具有审核权限、没有严重异常 | 原页变为已通过；点击返回队列继续处理下一单。 |
| 强制通过 | 待审核、有审核权限、填写原因并二次确认 | 原页显示已通过及强制通过记录；返回审核队列。 |
| 退回补充 | 审核人填写原因并确认 | 原页变为退回补充；审核人返回队列，员工从待办重新进入修改。 |
| 撤回审核 | 已通过；主管或管理员填写原因 | 原页回到待审核，再修改和审核；返回来源列表。 |
| 删除整张草稿 | 有删除权限、状态为草稿、确认删除 | 返回单据中心；原详情再次打开时说明已删除。 |
| 删除草稿图片 | 草稿中选定图片并确认 | 留在详情，更新页码与来源明细，提示重新核对总价；删除最后一页时明确说明整张草稿也将删除。 |

存在未保存修改时，离开详情提供“保存并离开 / 放弃修改 / 取消”；保存失败留在原页，不丢失输入。

## 五、公司Logo上传与适配规则

后续实施时，在**系统设置 → 企业品牌**中预留管理员专属入口：

- **上传与替换：** 支持PNG、WebP、JPG，优先使用透明底正式Logo；替换前预览电脑与手机效果。
- **展示区域：** 电脑侧栏顶部使用独立白色品牌区；手机首页、上传页使用紧凑品牌位，任务详情降低Logo视觉权重。
- **比例与留白：** 等比缩放，保留完整标志及文字，不拉伸、不加圆形裁切、不叠加阴影。
- **界面命名：** 公司Logo与“食安链·单据核验”产品名称分别展示，避免重复制作公司品牌字。
- **状态处理：** 未上传显示公司名称；选择后先预览；保存成功全局更新；上传或保存失败保留旧Logo并说明原因。
- **颜色稳定：** 替换Logo不自动改变成功、提醒、错误等业务颜色。当前金棕色板作为本轮统一基准。
