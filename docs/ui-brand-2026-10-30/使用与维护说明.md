## 界面与流程

- 工作台：优先处理草稿、待审核和退回单据；采购额仅统计授权范围内已通过单据。手机以卡片显示单据。
- 录入：先选项目和归档日期，再拍照或选相册，一单最多 5 页。手机底部固定上传按钮。尚未上传的图片离开前提醒。
- 单据校正：大屏原图/明细表/依据三栏，中屏两栏加依据抽屉；手机第一行展开，其余折叠，数量/单位/单价/金额两列。点击提醒可展开并定位明细；有来源页可打开对应原图，不猜测缺失页码。
- 手机顶部“更多”提供增加行、单据信息与供应商、处理依据与记录、重新比对及按权限显示的撤回/删除；材料的品名/规格/清除匹配/新建/删除保留在该行“更多字段与操作”。折叠不清空输入。
- 录入成功使用replace进入详情；详情返回按钮默认回单据中心，浏览器后退回上传前的有效历史页，不返回已提交上传页。录入前的返回来源在工作台与单据中心之间保持。
- 金额通常显示两位小数；单价原业务支持四位，超过两位的实际值保留精度，不因显示格式被截断。改数量/单价后仍按原业务规则计算行金额。
- B06 已补齐统一离开保护：站内返回、浏览器前后退会在有未保存内容时提示；可取消、暂存离开、明确放弃，单据可保存后离开。上传/保存中等待完成；保存或暂存失败继续留在原页。
- 审核：严重异常禁用普通通过；退回与强制通过必须填写原因，强制通过二次确认。权限和异常最终由服务器校验。
- 分析：显示平均单价和最高/最低成交价差；矩阵颜色仅表示相对高低。选材料查看同规格、同单位采购历史，再进入来源单据。导出和历史使用已经查询的日期/项目条件。
- 单据中心、分析、原材料和审核队列记住当前会话的筛选/选择及滚动位置。退出登录清除记忆；筛选记忆不包含表单草稿或密码，编辑恢复使用下面独立机制。
- 详情通过 `from=dashboard|documents|reviews|analytics|ingredients` 返回来源页面；非法来源忽略。列表页仍可从导航返回工作台。

## 未保存内容恢复（B06）

2026-10-30 已上线，6项公网检查通过；最新镜像、备份与回退依据见 `../releases/2026-10-30-navigation-recovery.json`。

单据字段、明细、备注、审核说明，以及录入页图片、顺序、项目和日期会在本浏览器暂存。选择“暂存并离开”后，从页面顶部“继续录入/继续校正单据”或原单据进入即可恢复。它不是服务端保存，不会提交审核或调用 OCR。

暂存按账号、标签页会话和单据区分，使用 IndexedDB，最多保留 12 小时；关闭浏览器期间不运行清理，过期副本下次访问时删除且不会恢复。图片保存原始字节及文件元数据，不压缩、不保存密码，不同步其他设备。独立新标签页不会自动带入；浏览器“复制标签页”可能复制会话标识，列入实机检查，不将其当成严格安全隔离边界。

保存/上传成功、明确放弃或退出登录后清理恢复副本。需要保留的内容应先保存再退出。若提示暂存失败，保持页面打开并保存或上传；“暂存并离开”不会在写入失败时放行。服务器版本、状态或权限已变时，展示原输入供核对，不自动覆盖新数据。

浏览器关闭/跨文档返回尽力显示原生提示，提示能否出现由浏览器决定；内容恢复靠已完成的持久化写入。主动清空浏览器数据、无痕环境关闭、系统在写入完成前强杀无法保证恢复。手机原生返回/手势与微信内置浏览器仍需 H03 真机验收。

维护入口：`LeaveProtection.tsx`、`history-guard.ts`、`draft-store.ts`；浏览器数据库为 `delivery-edit-recovery-v1`，对象仓库 `drafts`，只有会话标签 ID 放在 sessionStorage。新增编辑页须显式接入保护，不要另外加伪造历史页或全局自动保存。

本轮验证见 `b06-validation-summary.json`，发布、备份和回退见 `../releases/2026-10-30-navigation-recovery.json`。没有数据库迁移，不重新上传企业 Logo。

## Logo 管理

管理员进入「系统设置 → 企业品牌」，选择图片预览后点击「保存企业Logo」。支持 PNG/JPG/WebP，最大 2MB、1600万像素。上传失败不覆盖旧图，多人同时编辑发生版本冲突时刷新后重试。可以取消选择或确认移除。

原始字节存入既有 `SystemSetting` 表的 `company.brand`，不新增数据库表或迁移。像素分析仅测量外围空白，SVG 的 viewBox 收紧展示区域，原图不被裁切或重编码。适配登录页、侧栏和手机品牌区。Logo 为公开品牌内容，公开接口只提供元数据与图像；修改需要管理员会话、来源校验和版本校验。

接口：`GET /api/brand` 元数据，`GET /api/brand/logo` 原图，`POST /api/brand` multipart 的 `logo`、`version` 上传，`DELETE /api/brand` JSON `version` 移除。审计动作 `brand.logo_uploaded` / `brand.logo_removed` 只记录版本与摘要，不记录图片字节。

Logo 随数据库备份，不进入 Git；恢复旧应用镜像不会删除已存 Logo，旧版只是不读取该配置。回滚应用必须同步切换 Web 与 Worker，数据库恢复另行处理，禁止为了界面回退覆盖后续业务数据。
