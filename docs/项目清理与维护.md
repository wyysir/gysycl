## 日常可再生缓存清理

在项目根目录执行，默认只预览：

```powershell
powershell -File scripts/clean-local.ps1
powershell -File scripts/clean-local.ps1 -Apply
```

脚本只选根目录 `.next/`、`.npm-cache/`、`tsconfig.tsbuildinfo`，以及 `.tmp/`内明确名为 `.next/`或 `.next-ledger/` 的构建目录。跳过数据、依赖和浏览器运行目录；拒绝带联接祖先的目标，删除构建内目录联接本身但不遍历目标；检测到Next.js/npm运行进程时拒绝执行。不要同时启动构建或安装依赖。

每次执行的计划、逐项完成情况和字节计数存入 `.data/maintenance/cache-cleanup-时间.json`，不入Git。清理后运行 `npm run typecheck`重建类型；`npm run dev`或`npm run build`重建开发/生产产物。npm缓存会在后续安装时自动重新下载。不要把删除的缓存字节数当成后续构建后磁盘净变化。
