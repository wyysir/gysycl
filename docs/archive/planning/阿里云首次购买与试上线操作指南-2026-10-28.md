## 2. 先理解购买顺序

域名是网址中的名字，服务器是放系统的电脑，证书让访问地址使用 HTTPS。这三项配好后才能形成可用的系统入口，购买域名不会自动生成已上线的网站。

建议顺序：准备公司账号与资料 → 注册域名 → 购买 ECS → 立即提交网站备案 → 等待期间开通 OCR 和百炼并准备部署 → 申请证书 → 备案通过后开放域名访问 → 真单验收与备份。

证书可提前通过 DNS 验证申请，但等部署接近完成再签发，能减少免费证书有效期的消耗。等待备案时可以安装软件、准备数据及从受控测试环境验证 API；不要把尚未备案的域名直接作为正式网站对外开放。

## 5. 购买 ECS：逐项填选

入口：[ECS 产品页](https://www.aliyun.com/product/ecs) → 选型与购买，或[实例自定义购买页](https://ecs-buy.aliyun.com/wizard/)。购买页需要登录，本次未取得用户账号下的实际报价。

1. 选择“自定义购买”。计费方式选“包年包月”。
2. 地域选“华东1（杭州）”；网络选默认 VPC 和交换机即可，可用区按库存选。地域购买后不能直接变更。
3. 查找通用算力型 u1，选择 **4核8GB**；规格 ID 可核对 `ecs.u1-c1m2.xlarge`。缺货或总价明显不合适时，比较同配置 u2i。
4. 镜像选择“公共镜像 → Ubuntu → 24.04 LTS 64位 x86”。使用基础系统镜像，本项目无需购买建站应用镜像。
5. 系统盘改为 100 GiB ESSD Entry；可选数据盘先不加。若磁盘类型被实例限制，改选可用的普通 ESSD 并重新看总价。
6. 勾选“分配公网 IPv4”，带宽选“按固定带宽，5 Mbps”。本方案直接使用实例公网 IP，无需再买独立 EIP 或 NAT 网关。
7. 安全组选新建或默认，购买后核对规则：80、443 供网页访问；22 远程管理尽量只允许当前管理电脑公网 IP。3000、5432、6379 不向公网开放。若用 Workbench，按其连接方式的官方要求补齐管理入口。
8. 登录凭证选自定义强密码，支持时使用普通管理用户 `ecs-user`；自己妥善保存。服务器用户名和密码与系统里的管理员账号不同。
9. 实例名称可填 `shian-trial`，数量 1，期限 1 年。付款前保存订单配置和总价，核对续费价格。
10. 审阅是否有额外付费项目。系统自带基础防护可按条款保留，付费安全升级、运维服务和其他套餐仅在你明确需要时购买。
11. 支付后在[ECS 控制台](https://ecs.console.aliyun.com/)等待实例变为“运行中”，记录实例 ID、地域、公网 IP、系统、到期时间。

完成标准：控制台能看到正确的 4核8GB 实例，并能用“远程连接/Workbench”登录。

官网的 99 元活动实例公开配置为 2核2GB，不是本文所选 4核8GB。不要用该广告价估算此配置总价。即使看到 4核8GB 活动，也要核对资格、带宽、磁盘、年限及续费金额。

依据：[自定义购买操作](https://help.aliyun.com/zh/ecs/user-guide/create-an-instance-by-using-the-wizard)、[U 实例规格](https://help.aliyun.com/zh/ecs/user-guide/general-work-force)、[99 元活动配置](https://www.aliyun.com/activity/ecs/99program)。

## 7. 开通 OCR：选表格识别按量付费

入口：[官方通用文字识别产品](https://ai.aliyun.com/ocr/general) → 控制台/开通服务。项目对应接口为 `RecognizeTableOcr`，不是旧版 `RecognizeTable`，也不是只适合标准发票的识别套餐。

1. 用主账号在文字识别 OCR 控制台开通“通用文字识别”，查看其中“表格识别”的按量付费说明并同意开通。
2. 先用官方体验馆上传 1–2 张脱敏送货单看效果。体验馆可用不等于程序 API 已接通，随后还要做实际接口联调。
3. 本轮先按调用量计费，不购买大资源包。该服务开通本身不收费，产生有效计费调用后按规则结算。
4. 在 RAM 访问控制 → 身份管理 → 用户，创建项目专用用户，例如 `shian-ocr`。程序访问使用它的 AccessKey，不使用主账号 AccessKey。
5. 授权时，运行程序的最小操作为 `ocr:RecognizeTableOcr`，资源范围 `*`；可通过 RAM 自定义策略的可视化编辑器选择该操作并授权。若先用官方系统策略 `AliyunOCRFullAccess` 联调，它覆盖全部 OCR 功能，范围更大，后续应收窄。不要授予整个云账号管理员权限，也无需为运行账号增加账单签约权限。
6. 打开该 RAM 用户 → 凭证管理 → 创建 AccessKey，按页面用途选择和提示创建。保存 AccessKey ID、AccessKey Secret，真实 Secret 只填服务器配置，不写进项目文档或聊天。
7. 服务器部署时，分别填写项目配置 `ALIYUN_ACCESS_KEY_ID`、`ALIYUN_ACCESS_KEY_SECRET`；接入地址使用 `ocr-api.cn-hangzhou.aliyuncs.com`。
8. 用该用户凭据实际调用 1 张单据，确认权限和计费服务已生效，保存不含密钥的调用结果或请求 ID。

现有代码已传入手写识别、旋转及无线表格相关参数，不需再为了手写单额外买“通用手写体识别”套餐。

费用：公开按量表中，表格识别首档为 **0.0825 元/次**，更高用量按月累进阶梯。当前项目每页图片调用一次表格 OCR，3 页单通常是 3 次；失败后的有效重试、重新识别可能增加费用。免费额度以账号服务页面为准，不能按每个 RAM 子用户重复领取计算。

如果以后用量稳定，再比较官方表格资源包的有效期、实际可抵扣 API、按次/按点换算与单价。云市场第三方资源包不能默认抵扣本项目正在调用的官方接口。

依据：[接口及权限](https://help.aliyun.com/zh/ocr/developer-reference/api-ocr-api-2021-07-07-recognizetableocr)、[开通步骤](https://help.aliyun.com/zh/ocr/getting-started/use-process)、[AccessKey 创建](https://help.aliyun.com/zh/ram/user-guide/create-an-accesskey-pair)、[按量价格](https://help.aliyun.com/zh/ocr/product-overview/pay-as-you-go)、[资源包规则](https://help.aliyun.com/zh/ocr/product-overview/resource-plans)。

## 8. 开通百炼：按量调用视觉模型

入口：[阿里云百炼控制台](https://bailian.console.aliyun.com/)。本项目需要模型 API 服务；无需先购买聊天会员、Coding Plan、GPU、自行部署模型或训练套餐。

1. 首次进入按页面提示开通模型服务，地域选择 **华北2（北京）**。
2. 模型广场查找 `qwen3-vl-plus`，确认当前账号可调用。它负责读图、整理供应商/日期/数量/金额等字段，和表格 OCR 两条通道配合。
3. 用 1–2 张脱敏单据在体验页测试；然后从项目实际接口验证返回结构化字段。体验页面聊天成功本身不足以证明集成成功。
4. 进入“API Key/密钥管理”，创建专用 Key。先使用默认业务空间即可，权限允许实际选择的视觉模型；Key 名称按界面可用的名称或备注功能标记项目。
5. 保存 API Key 到服务器配置。百炼 API Key 和 OCR 的 AccessKey ID/Secret 是不同凭据，不能互换。
6. 服务器配置对应关系：

| 项目配置项 | 本指南建议值 |
| --- | --- |
| `DASHSCOPE_API_KEY` | 你新建的北京地域 API Key，仅填写于服务器 |
| `DASHSCOPE_BASE_URL` | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| `QWEN_VL_MODEL` | `qwen3-vl-plus` |

ECS 选杭州而百炼 Key 选北京可以配合使用，关键是百炼 Key、模型与接入地址属于同一服务地域，不能拿新加坡 Key 配北京接入地址。

7. 本模型使用非思考模式；官方说明 `qwen3-vl-plus` 默认关闭思考，支持 JSON 结构化输出。项目现有请求就是图片加 JSON 格式要求。当前仓库模板默认的 `qwen-vl-max-latest` 不直接照抄到这次部署；官方结构化输出支持范围有版本限制，本轮建议通过环境配置选择上述候选，并以真实调用结果验收。本文未修改代码或本地 `.env`，未承诺真单准确率。
8. 到“费用用量 → 预算管理”为本项目 Key 设置试用月预算，例如 50 元，预警阈值 80%。个人试用阶段可开启“达到预算后立即停止”，接受额度用尽识别暂停；停服有延迟，可能略超预算。扩大正式业务前应重新评估预算及停服策略。
9. 到费用用量查看真实的输入、输出 Token 和账单。Token 可理解为模型计费的处理量，图片也会折算为输入量，不能当成单据张数。

公开价格：北京地域 `qwen3-vl-plus` 在单次输入不超过 32K Token 时，输入 **1 元/百万 Token**、输出 **10 元/百万 Token**；超过 32K 会进入更高单价阶梯。免费额度是否可用、剩余多少及有效期看自己控制台。

阿里云“费用与成本”的普通预算预警只发通知，不会自动限制 ECS/OCR 的消费；百炼自己的预算管理另外支持达预算停 API。两者要区分。

依据：[API Key 和北京接入地址](https://help.aliyun.com/zh/model-studio/get-api-key)、[结构化输出支持](https://help.aliyun.com/zh/model-studio/qwen-structured-output)、[视觉模型模式](https://help.aliyun.com/zh/model-studio/vision)、[模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)、[百炼预算](https://help.aliyun.com/zh/model-studio/budget-management)、[云账号普通预算](https://help.aliyun.com/zh/user-center/how-to-manage-a-budget)。

## 9. 域名解析与 HTTPS 证书

### 把业务域名指向服务器

入口：域名控制台 → 解析，或[云解析 DNS](https://dns.console.aliyun.com/)。

1. 选择实际购买的主域名，点击“添加记录”。
2. 类型选 `A`，主机记录填 `shian`，记录值填 ECS 控制台显示的公网 IPv4，线路和 TTL 使用默认值。
3. 保存。以后访问的业务地址就是 `https://shian.实际域名`。

这里 A 记录是“告诉浏览器去哪个服务器”，证书验证用的 CNAME/TXT 则是“证明域名归你”，用途不同。基础解析足够本轮试用。

依据：[DNS 入门](https://help.aliyun.com/zh/dns/beginner-s-guide)、[子域名配置](https://help.aliyun.com/zh/dws/getting-started/configure-domain-name-resolution)。

### 在阿里云申请证书

入口：[数字证书管理服务](https://www.aliyun.com/product/ssl-certificate) → 控制台 → 证书管理/SSL 证书管理 → 个人测试证书。

1. 点击“立即购买/领取”，选“个人测试证书（免费版）”。免费基础额度本身为 0 元，检查没有额外选择付费自动化或专家服务。
2. 领取额度后创建、申请一张证书，绑定 `shian.实际域名`。该证书保护这个确切的业务地址；不要误申请为主域名后期待自动覆盖所有子域名。
3. 同账号管理 DNS 时按页面使用自动 DNS 验证；否则按证书页给的名称和值添加 CNAME/TXT。
4. 按页面填写联系人；算法可选通用的 RSA_2048，CSR 选系统生成。
5. 审核签发后下载 **Nginx** 格式证书及私钥，妥善保存。申请证书不等于已安装到网页服务。
6. 部署时将证书配置到服务器 Nginx，验证 HTTPS、80 到 443 跳转、页面登录及手机上传。配置工作应由有服务器权限的部署者完成。
7. 记录实际证书到期日，提前 30 天检查，至少提前 14 天完成新证书申请、替换与访问验证。这里是维护安排，没有创建自动提醒任务。

官网免费测试证书为 90 天，每个实名主体每自然年最多 20 张；到期需重新申请并部署。官网同时列出 pro 测试证书参考为 34 元/张、服务周期 6 个月，仍属测试证书，也不等于免维护。持续正式业务如选择付费，选“正式 SSL → DV 单域名”，核对品牌、实际服务周期和重签/部署方式；单个业务地址无需通配符或 OV/EV 作为前置。

依据：[测试证书领取与费用](https://help.aliyun.com/zh/ssl-certificate/purchase-an-individual-test-certificate)、[申请与 DNS 验证](https://help.aliyun.com/zh/ssl-certificate/apply-for-a-certificate)。

## 10. 费用怎么算

| 类别 | 本轮怎样核算 |
| --- | --- |
| ECS 固定费用 | 以登录后的“4核8GB + 100GiB盘 + 5Mbps固定带宽 + 1年”的订单合计为准，另看续费价；本次未取到账户实价 |
| 域名 | 看所选普通 `.com` 的首年和续费价，域名未定无法给出实际订单价 |
| HTTPS | 上述免费试用证书基础费用 0 元；付费证书/自动化/专家服务分别计价 |
| OCR | 图片页数对应成功计费调用量，按月阶梯计费或适用资源包抵扣 |
| 百炼 | 输入 Token × 输入价 + 输出 Token × 输出价，阶梯看单次请求输入量 |
| 备份/快照等 | 独立备份介质、云快照或以后新增 OSS 费用另计，不能当成购买 ECS 已全部包含 |

算例只帮助理解计费，未用本项目真单测得 Token：假设 100 张单、每张 3 页，不考虑免费额度、重试和优惠，OCR 为 300 × 0.0825 = 24.75 元；若每张单百炼输入 10,000、输出 2,000 Token，百炼约 3 元，识别合计约 27.75 元。每月 1,000 张相同样本约 277.50 元识别费。此算例不含服务器、域名、证书、备份，也不承诺实际单据费用或准确率。

先上传 5–10 张真单，查看调用量、耗时及账单后，再决定月度备用金与资源包。旧采购材料按全公司规模测算，本次单机试用不沿用旧总预算作为报价。

## 11. 买好后怎样才算上线完成

你负责实名、付款、域名命名、备案实人核验和账号中凭据的保管；获得访问条件后，软件安装、部署配置及联调可以继续由助手协助完成。

部署者应基于本次选型执行现有脚本并核查实际行为，不能认为云产品购买后自动装好了食安链：

1. 安装 Docker、Compose、Nginx，上传当前源码，应用与 Worker 使用同一版本。
2. 配置正式 PostgreSQL、Redis，挂载数据库和图片持久卷；`DEMO_MODE=false`，使用真实 OCR，设置独立会话密钥。
3. 核对应用只在本机或受控网络监听，Nginx 对外提供 HTTPS。原 Compose 有 `3000:3000` 映射，部署时要处理绑定和安全组，不照搬为公网入口。
4. 在应用及 Worker 两侧填写 OCR 和百炼配置，核实权限、北京 Key 与地址、模型名。
5. 创建自己的应用管理员，录入小批量主数据。
6. 先用 1 张清楚单据验证两条通道均成功，再用 5–10 张真单完成上传、校正、提交、审核、导出和退回重提。
7. 将数据库备份、上传图片副本、必要的部署与恢复说明保存到服务器之外，至少做一次恢复验证与服务重启检查。服务器快照不能替代所有业务恢复检查。

不要把项目 `/api/health` 成功当成全部验收：它不能替代 Worker 队列、真实识别通道和手机访问验证。
